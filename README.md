# OnixBans
Плагин для Minecraft 1.21.x, разработанный merser2330 под лицензией MIT.

Позволяет администраторам эффективно управлять нарушениями на сервере: блокировать игроков (ban), исключать их (kick) и накладывать мут (mute), а также снимать соответствующие ограничения (unban, unmute).

# Основные функции:
Управление игроками:
блокировка (ban) — полное исключение игрока с возможностью указания причины и срока;
исключение (kick) — мгновенный кик игрока с сервера;
мут (mute) — запрет на отправку сообщений в чат на заданный период;
снятие ограничений (unban, unmute) — восстановление доступа и прав игрока.
Интеграция с Discord через Webhook:
автоматическое логирование всех действий в Discord‑канале в виде embed‑сообщений;
цветовая индикация типа действия через цвета embed (в десятичной системе):
kick — 1677696016776960 (жёлтый);
ban — 1671168016711680 (красный);
mute — 1019791510197915 (серый);
unban — 6528065280 (зелёный);
unmute — 6528065280 (зелёный).
Локальное хранение данных:
все данные о блокировках, мутах и исключениях сохраняются в локальном Data‑файле;
защита от некорректных изменений: если файл редактируется при работающем сервере, плагин автоматически восстанавливает предыдущую версию;
правка файла разрешена только при выключенном сервере — это гарантирует целостность данных и предотвращает конфликты при одновременном доступе.

оперативно реагировать на нарушения;
вести прозрачный учёт блокировок и ограничений;
интегрировать систему наказаний с Discord для мониторинга и отчётности;
обеспечить надёжное хранение данных с защитой от случайных или намеренных изменений.
